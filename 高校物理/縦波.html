縦波の横波表示とは？

音波などの「縦波」は、媒質（波を伝える物質）が波の進む方向と同じ方向に振動します。そのため、そのまま図に描くと「疎密」があるだけで波の形が見えにくくなります。

【変換のルール】

  • ● 媒質が右にずれる → グラフを上 (y > 0) に描く
  • ● 媒質が左にずれる → グラフを下 (y < 0) に描く

左の「波を動かす」ボタンを押して、上のグラフ（横波表示）と下の点（実際の媒質）の動きが連動していることを確認してください。

問題 (a) の解説

正解: d

「振動の中心からの変位が左向き」ということは、実際の媒質が元の位置より左にある状態を指します。

横波表示のルールを思い出すと、変位が左向き ＝ グラフのy座標がマイナス (y < 0) となります。

左の図を見てください。青色でハイライトされた y < 0 の領域（c と e の間） にある点は d です。下の媒質の点を見ると、d の点が元の位置（点線）より明確に左へズレているのがわかります。

問題 (b) の解説

正解: c

「最も密な点」とは、両側から媒質が押し寄せて集まっている場所のことです。

媒質が集まる条件をグラフの形で考えると以下のようになります。

  • 左側からは右向きに変位 (グラフが y > 0)
  • 右側からは左向きに変位 (グラフが y < 0)
つまり、「グラフがx軸と交わり、かつ右下がりになっている点」が密になります。左の図の赤い領域です。点 a~g の中でこれに該当するのは c と g です。（選択肢として c が適当です）

逆に、右上がりの交点（a, e）は両側に媒質が逃げていくため「疎」になります。
