基本パターン

「微分の定義」を使って
極限を解く、いちばん基本のやり方

急に sin や複雑な式が出てくる極限の問題も、実は「微分の定義」を知っているだけで 一瞬で解けることがあります。まずはこの基本パターンをしっかり押さえましょう。

1微分の定義を思い出す

「関数 f(x) の x=a における微分係数 f'(a)」は、こう定義されています。

f'(a)  =  limh→0 f(a+h) − f(a)h

この式が表しているのは「a という点のすぐ近くで、f(x) がどれくらいの割合で 変化しているか」＝a での接線の傾きです。

イメージでつかむ a という点から、ほんの少し（h だけ）先に進んだときの「変化の量 ÷ 進んだ距離」を 計算しています。h をどんどん 0 に近づけていくと、その割合は ある1つの値（a での傾き）に落ち着きます。それが f'(a) です。

2問題文の中に「定義の形」を見つける

入試や問題集でよく出るのは、次のような形の極限です。ぱっと見は 何をすればいいか分からなくても、「これは微分の定義の形をしている」 と気づけば、計算しなくても答えが分かってしまいます。

①

分子が「同じ関数」の差になっている

分子をよく見て、同じ関数 f が、少しだけ違う場所 （a+h と a など）で使われていないかを確認します。

②

分母が「その場所の差」になっている

分母が、分子で使った2つの場所の差（今回なら h）に なっているかを確認します。分子と分母がセットで対応していることが大事です。

③

f(x) と a を特定して、公式に当てはめる

「どんな関数 f(x) を使っているか」「どの点 a で見ているか」の2つさえ 分かれば、あとは f'(x) を計算して a を代入するだけです。

3いちばんシンプルな例で練習

練習1

次の極限を求めよ。

limh→0 sin(a+h) − sin ah

見抜き方：分子は「sin という同じ関数」が a+h と a で使われている。 分母はその差 h。→ これはそのまま微分の定義の形です。

f(x) = sin x とみると、この式は f'(a) そのもの。
f'(x) = cos x なので、f'(a) = cos a

答え：cos a（計算は一切不要で、公式に当てはめるだけ）

練習2（数値で確認）

次の極限を求めよ。

limx→2 x³ − 8x − 2

見抜き方：形が少し違って見えますが、8 = 2³ と気づけば、 分子は「x³ という関数」が x と 2 で使われている差になっています。

limx→2 x³ − 2³x − 2  =  f'(2)  （f(x) = x³ とみたとき）
f'(x) = 3x² なので、f'(2) = 3×2² = 12

答え：12

ここまでのまとめ 「分子が同じ関数の差」「分母がその場所の差」になっている極限を見たら、 とにかく微分の定義を疑ってみるのが第一歩です。 次のページでは、この基本パターンだけでは形が少し違う「今回の問題」を扱います。
対称差分商のからくり

今回の問題：
なぜ真ん中で分子を
「足して引く」だけで証明できるの？

今回の問題は、1ページ目の基本パターンとは少し形が違います。 分子が f(a+h) と f(a−h) の差で、真ん中の f(a) がありません。 この差を埋めるのが、これから見ていくテクニックです。

limh→0 f(a+h) − f(a−h)2h  =  f'(a)

0まず、何を証明したいのか

🎯
「a を中心に、左右対称な2点を結んだ直線の傾き」は、 h を 0 に近づけると「a における接線の傾き＝f'(a)」に一致する。

これがこの証明のゴールです。まずは図でイメージをつかんでから、式で確かめていきます。

1図でイメージをつかむ

h を小さくするほど、赤い直線（2点を結ぶ線）はどんどん緑の接線に近づいていきます。
「これを式でちゃんと確かめよう」というのが、以下の証明の内容です。

2証明を1歩ずつ

1

分子に「f(a)」をこっそり足して、引く

なぜ？→ 見た目を変えたいだけ、値はゼロなので変化なし

まず分子 f(a+h) − f(a−h) だけに注目します。ここに +f(a) と −f(a) を1つずつ挿入します。 足して引けば結局ゼロなので、式の値は何も変わりません。

f(a+h) − f(a−h)
  = [ f(a+h) − f(a) ] + [ f(a) − f(a−h) ]

この形にすると、2つのカッコの中身が、どちらも 1ページ目で見た「微分の定義」の分子（ある点との差）にそっくりの形になります。 これがこのテクニックのねらいです。

2

式全体を2つの塊に分ける

なぜ？→ それぞれを別々に、知っている極限の形に持ち込むため

元の式に STEP1 の結果を当てはめ、12h を 2つの項に配ります。

f(a+h)−f(a−h)2h  =  12  ×  [ f(a+h)−f(a)h  +  f(a)−f(a−h)h ]
3

1つ目の塊：そのまま微分の定義

なぜ？→ 1ページ目の公式とまったく同じ形

1つ目の塊 f(a+h)−f(a)h は、1ページ目で確認した定義の式とまったく同じ形です。だから h→0 の極限を取ると、 そのまま f'(a) になります。

4

2つ目の塊：h を −h に置きかえて考える

なぜ？→ 形は違って見えるが、実は同じ極限に行きつくことを確認する

2つ目の塊 f(a)−f(a−h)h は、パッと見は定義と順番が逆で戸惑うかもしれません。ここで一つ工夫をします。

微分の定義の式の「h」という文字を、そのまま「−h」に置きかえてみます （h→0 なら −h→0 でもあるので、極限としては全く同じ意味です）。

f'(a) = limh→0 f(a+(−h)) − f(a)−h  =  limh→0 f(a−h) − f(a)−h

分子・分母の符号をそろえて両方マイナスにひっくり返すと…

f'(a) = limh→0 f(a) − f(a−h)h
直感的なイメージ 「a から h だけ進んだときの変化率」も「a から h だけ戻ったときの変化率」も、 h をどんどん 0 に近づければ、どちらも同じ 1 つの値（a のところの傾き）に近づいていきます。 右から見ても左から見ても、行きつく先は同じということです。
5

2つの塊を合体させる

なぜ？→ STEP3とSTEP4の結果を、STEP2の式に戻すだけ

STEP3 と STEP4 で、どちらの塊も極限を取ると f'(a) になることが分かりました。これを STEP2 の式に戻します。

limh→0 f(a+h)−f(a−h)2h  =  12 × [ f'(a) + f'(a) ]  =  12 × 2f'(a)  =  f'(a)

これで証明が完成しました。

3今回の問題に当てはめる

今回は f(x) = sin x のケースでした。sin x を微分すると cos x になることは 知っている公式なので、そのまま代入します。

f(x) = sin x  →  f'(x) = cos x  →  f'(a) = cos a
limh→0 sin(a+h) − sin(a−h)2h  =  cos a

✓結論として

「分子に f(a) を足して引く」という一見不思議な操作は、 式を2つの「微分の定義の形」（1ページ目で学んだ基本形）に分解するための準備でした。

2つ目の塊は形が違って見えても、h を −h に置きかえることで、 1つ目と同じ f'(a) に収束することが確認できます。
